# Counter-Strike 2

This configuration is used to play from a 7 yo pc.

## Quick Info

- **Resolution:** 1280x1024
- **Aspect Ratio:** 16:9 bb
- **Monitor Size:** 24'
- **Input Device:** Keyboard & Mouse
- **Mouse DPI:** 1200
- **Ingame Sensitivity:** 0.95
- **VibranceGUI:** 205

## Launch options

```
-high -d3d9ex -novid -console -nojoy -tickrate 128 +fps_max 999 +rate 786432
```

## Game Data

### Configuration file(s) location

Windows path:

```
<Steam-folder>\userdata\<user-id>\730\local\cfg
```

### Save game data location

None.
